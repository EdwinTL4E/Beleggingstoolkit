Beleggingstoolkit is een compacte webtool met AI-prompts voor het analyseren van aandelen, ETF’s, marktsentiment en portefeuilles. De tool helpt beleggers om AI-platformen op een gestructureerde manier te gebruiken tijdens verschillende fases van de beleggingscyclus.

De toolkit bevat prompts voor fundamentele analyse, technische analyse, ETF-analyse, macro- en sentimentanalyse, portefeuillechecks en het volgen van markt- en bedrijfsnieuws. De prompts zijn direct te gebruiken in AI-platformen zoals ChatGPT, Claude, Google Gemini en Microsoft Copilot.

De applicatie is gebouwd met HTML, CSS en vanilla JavaScript en werkt volledig lokaal in de browser zonder installatie of externe dependencies.

Deze HTML-tool is bereikbaar via: https://edwintl4e.github.io/Beleggingstoolkit/
